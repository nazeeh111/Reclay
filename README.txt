Reclay browser laboratory

Serve this directory using an ordinary HTTP server, or deploy its contents as static HTTPS files. Opening file:// directly is unsupported. Both studios execute the shipped Python engine in a module Web Worker using pinned Pyodide314.0.7. First use requires internet access to jsDelivr for the Python runtime; there is no offline-first guarantee. Specimen bytes and inferred models stay in the browser and are never submitted to a computation server. Only packaged examples, source and runtime resources are fetched. Cancel terminates the worker, and a subsequent operation creates a fresh instance. Standalone Python editors exported by either studio need no Reclay installation.

Known supported model families and original validation: https://github.com/nazeeh111/Reclay . Model hashes and source hashes establish integrity identities, not authenticity, semantic completeness or universal safety.
